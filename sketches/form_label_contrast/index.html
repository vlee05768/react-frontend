📝 表單「名稱與內容」視覺層級對比優化

當欄位名稱（Label）設為方案 C 粗體高對比時，透過將「內容文字」微調稍淡（0.65 不透明度），能創造出極佳的視覺呼吸感與層級感，避免兩者顏色擠在一起。

調整前

顏色高度一致（缺乏層級）

視覺反饋

  • 名稱（Label）和內容（Value）的色彩飽和度都非常高。
  • 當整張表單有很多欄位時，所有字體擠在一起，使用者很難在 0.1 秒內迅速區分「哪個是欄位名、哪個是資料內容」。
極佳層級 (推薦)
調整後

內容文字稍淡（層級分明）

視覺優勢

  • 欄位名稱：深黑色粗體，依然極為明顯。
  • 內容文字：調整為稍淡的 `rgba(0,0,0,0.65)` / `rgba(255,255,255,0.65)`。
  • 當欄位名和內容粗細、深淺分明時，表單可讀性顯著提升！

🛠️ ERP 系統中的全域實作方式 (AntD & CSS)

我們可以透過在 src/App.tsx 中修改全域輸入框文字顏色（即 `colorText`），或者在 src/index.css 中套用 Input / Select 等輸入框的預設字體顏色。為了維持最穩定的系統架構，我們直接透過 `ConfigProvider` 覆蓋 `colorText` 元件級樣式：

// 於 src/App.tsx 的 ConfigProvider > theme > components 增加 Input / Select 的色值控制 <ConfigProvider theme={{ token: { // 全域共通 Token components: { Form: { marginLG: 16, labelColor: mode === 'dark' ? 'rgba(255, 255, 255, 0.85)' : 'rgba(0, 0, 0, 0.85)' }, // 🔥 調整輸入框內容文字顏色稍淡 (0.65 不透明度) Input: { colorText: mode === 'dark' ? 'rgba(255, 255, 255, 0.65)' : 'rgba(0, 0, 0, 0.65)' }, // 🔥 調整 Select 下拉選單選中文字顏色稍淡 (0.65 不透明度) Select: { colorText: mode === 'dark' ? 'rgba(255, 255, 255, 0.65)' : 'rgba(0, 0, 0, 0.65)' } } }} >
